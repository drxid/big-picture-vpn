# Оформление для Steam

Готовые изображения для библиотеки Steam. Все сделаны в том же визуальном
языке, что и приложение: почти чёрный фон, один зелёный маяк, Segoe UI Variable
с плотным трекингом. Маяк выбран знаком не случайно — после первого же запуска
приложения он уже связан с «туннель поднят».

| Файл | Размер | Куда идёт |
|---|---|---|
| `grid-vertical-600x900.png` | 600×900 | Вертикальная обложка в библиотеке |
| `grid-horizontal-920x430.png` | 920×430 | Горизонтальная плитка, «Недавние» |
| `hero-1920x620.png` | 1920×620 | Широкий баннер на странице игры |
| `logo.png` | 1280×720 | Логотип поверх баннера, прозрачный фон |
| `icon.png` | 256×256 | Иконка, прозрачный фон |

Исходник — `assets/steam-art.html`. Он рендерится ровно в целевом разрешении,
поэтому картинка на выходе пиксель в пиксель повторяет макет. Композиция
выбирается хэшем: `#vertical`, `#horizontal`, `#hero`, `#logo`, `#icon`.
Логотип и иконка рисуются в canvas, а не скриншотом — только так получается
прозрачный фон.

## Поставить в свой Steam

Проще всего через интерфейс: правой кнопкой по игре в библиотеке →
**Управление** → **Настроить изображение** (отдельно для обложки, баннера и
логотипа).

Либо положить файлы напрямую, назвав их по `AppID` нестандартной игры:

```
Steam\userdata\<SteamID3>\config\grid\
    <appid>.png        горизонтальная плитка
    <appid>p.png       вертикальная обложка
    <appid>_hero.png   баннер
    <appid>_logo.png   логотип
```

## Загрузка на SteamGridDB

Учти: SteamGridDB хранит оформление для игр, которые уже есть в его базе.
Своё приложение там сначала должно появиться как запись — просто загрузить
файлы «в никуда» не выйдет. Порядок такой:

1. Зайти на https://www.steamgriddb.com и войти через Steam.
2. Найти приложение поиском. Если его нет — добавить через раздел для
   нестандартных игр (у сайта есть форма запроса, плюс запросы принимают в их
   Discord).
3. На странице приложения открыть нужную вкладку — **Grids**, **Heroes**,
   **Logos**, **Icons** — и загрузить соответствующий файл.

Размеры здесь уже совпадают с теми, что сайт считает основными, так что
изображения не будут пережаты при загрузке.
